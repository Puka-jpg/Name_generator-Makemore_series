# 🇳🇵 Nepali Name Generator (Makemore-inspired)

This project is a character-level name generator trained on Nepali names using a neural network built from scratch, inspired by [Andrej Karpathy’s makemore](https://github.com/karpathy/makemore).

It takes a dataset of real Nepali names and learns to generate new, realistic-sounding names by predicting one character at a time.

## 📌 Features

- Clean dataset of Nepali names (`names.txt`)
- Manual implementation of:
  - Tokenization
  - One-hot encoding
  - Forward and backward pass
  - Simple neural network with one hidden layer
- Loss tracking & visualization
- Sampling from the trained model to generate new names

## 🧠 Model Architecture

- Input: One-hot encoded characters (vocab size ≈ number of unique characters)
- Hidden layer: 100 neurons (ReLU activation)
- Output: Probability distribution over next characters (softmax)
- Training: Cross-entropy loss + backpropagation

## 🗂️ Files

- `nepali_name_generator.ipynb`: Main Jupyter Notebook with the full training and generation code
- `names.txt`: Dataset of Nepali names (one per line)
- `README.md`: You're reading it 🙂

## 📊 Training Progress

The model is trained for a number of epochs while tracking the loss. As training progresses, the loss decreases and the quality of generated names improves.

## 🔧 Requirements
